# Competitive Programming Tracker — Frontend

React + Vite + Tailwind frontend for the Competitive Programming Tracker.

## Run locally

```powershell
npm install
npm run dev
```

Default URL:

`http://localhost:5173`

Backend API:

`http://localhost:8080/api`

To override the API URL, create `.env`:

```text
VITE_API_URL=http://localhost:8080/api
```

## Build

```powershell
npm run build
```

## Lint

```powershell
npm run lint
```

The frontend includes JWT authentication, protected routes, dashboard, problem tracking, platform statistics, goals, planner, achievements, notifications, reports, and admin pages.
